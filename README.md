### Now building

**[werkflow](https://github.com/themaverik/werkflow)**
Open-source enterprise workflow automation on Flowable BPM, Spring Boot and
Next.js. Most BPM platforms force you to choose between a visual designer
business users can operate and a codebase engineers can actually maintain.
Werkflow is an attempt at both.

**[claude-code-project-workflow](https://github.com/themaverik/claude-code-project-workflow)**
An opinionated Claude Code setup: layered CLAUDE.md and LLM.md docs, lazy-loaded
skills, and ADR capture via Log4brains. Built because AI coding assistants lose
architectural context between sessions, and re-explaining a system every morning
is not a workflow.

### Shipped

**[guided](https://github.com/themaverik/guided)**
Renders A4 print-ready, image-driven product guides from a structured schema.
Built to fight content rot: in a product that ships weekly, hand-made
screenshot guides are stale before they are published.
